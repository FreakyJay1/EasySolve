# EasySolve

EasySolve is a small website we built for a made-up web company as a course project. It's plain HTML and CSS, with no frameworks or build step.

The company pitch is simple: web design, web development, hosting and app development for small businesses.

## Pages

- `index.html` - home page with the hero, the main services and a call to action
- `Pages/Service.html` - what we offer, plus a section of client reviews
- `Pages/about.html` - the company story, some numbers, and the team

## Running it

Nothing to install. Clone the repo and open `index.html` in your browser.

## Layout

```
index.html
Pages/     service and about pages
css/       global.css plus one stylesheet per page
assets/    team photos and the hero/who-we-are images
images/    service icons and client photos
```
